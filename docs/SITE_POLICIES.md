# FAQ・利用規約・プライバシーポリシー

公開先は `faq/`、`terms/`、`privacy/`。静的HTMLなのでJavaScriptが無効でも本文を読めます。フッターからアクセスでき、GitHub Pagesのビルド対象に含めています。

FAQは現行実装のログイン、投稿、共有、ファイル制限、削除、読み込みの制約を説明します。利用規約・プライバシーポリシーは運営情報が未確定のためドラフト表示とnoindexを付けています。検索エンジンのnoindexはアクセス制御ではありません。この状態のまま正式なポリシーとして公開しないでください。

正式公開前に運営者が確定する内容:

- アカウント・監査履歴・接続ログ・バックアップの保存期間、削除の運用
- 利用中の外部サービスの保存リージョンと国外での処理の説明
- 規約・ポリシーの適用日、変更の告知方法

確定した内容をterms/index.html・privacy/index.htmlへ反映してからドラフト表示・noindexを取り除きます。原稿内の「正式公開前」「正式公開時」の箇所を見直してください。単なるページ追加では、利用者の規約同意を取得・記録する機能は導入されません。

ホームは既存のダーク配色とライト配色に対応し、2行のコピーを維持して、検索・選択タグ・ゲーム一覧を同じセクションにまとめています。ゲーム検索の状態や認証は既存実装を利用します。

運営者の表示名は「GAMEPORTAL運営」。ユーザー指定により問い合わせ窓口は設けず、問い合わせフォーム・連絡先・受付の案内は追加しません。

配色はデバイス設定を初期値とし、共通フッターで「デバイス設定／ライト／ダーク」を選べます。選択はlocalStorageの `game-portal.theme.v1` に保存します。保存を拒否するブラウザーでも、そのページ内で切り替えできます。「デバイス設定」ではOSの表示モードの変更にも自動追従します。明示的にライト／ダークを選んだ場合は、その選択を優先します。ゲーム内の配色は変更しません。

検索対象・一致条件・タグ選択は単一の「検索オプション」にまとめています。選択中のタグはパネルを閉じても確認・解除できます。

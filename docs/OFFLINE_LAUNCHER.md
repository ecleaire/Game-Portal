# Windows オフラインゲームランチャー

Windows x64向けのElectronアプリです。現在のWebサイトと別に起動し、Supabase・Google Drive・ログインに接続せず使用します。

## 使い方

1. Windows向け配布ファイル `GAME-PORTAL-0.1.0-Windows-x64.exe` を起動します。
2. 「フォルダーを選択」で、ゲームを保管する端末内のオフラインフォルダーを選びます。指定先の `GAMEPORTAL-library` 内に保存します。OneDrive等の同期対象外のフォルダーを推奨します。USBも使用できますが、起動時に接続が必要です。
3. 「ゲームを取り込む」で `.zip` / `.html` / `.htm` を選択します。ZIPは50MB、展開後200MB、500ファイルまで。GodotはWeb書き出し一式をZIPにし、Scratch / TurboWarpは素材を含むHTMLまたはZIPにしてください。`.exe` / `.sb3` / Godotプロジェクト自体の実行には対応しません。
4. ライブラリから「プレイ」で別ウィンドウを開きます。ネット接続なしで起動できます。ゲームから外部サーバーへの通信、外部リンク、ダウンロード、端末権限要求は許可しません。オンラインAPI・CDN・外部素材が必要な作品は、作者がオフライン対応する必要があります。
5. 「削除」は確認後、このランチャーが保存したゲーム本体とそのセーブデータを削除します。取り込み元のHTML・ZIPは残します。プレイ中は削除できません。

保管先を切り替えても元のフォルダーは残ります。元のフォルダーを選び直すと一覧に戻ります。保管先のパスだけをアプリ設定に保存し、ゲーム本体・メタデータ・ゲームごとのブラウザー保存データはオフラインフォルダーへ保存します。移行・バックアップ時はゲームを終了して `GAMEPORTAL-library` 全体をコピーしてください。空き容量・USB接続を確認してください。

ゲームはローカルファイルとして保管し、配信停止・BAN・共有解除をオンラインで照合する機能は持ちません。この版は手元のHTML/ZIPを取り込む独立したランチャーです。既存サイトの共有作品や非公開作品を自動ダウンロードする機能はありません。

## 開発・配布

```sh
npm ci
npm run launcher:dev
npm run launcher:test
npm run launcher:build:win
```

Windows上でのビルドを基本とします。GitHub Actionsの **Build Windows offline launcher** からWindows x64のportable EXEを生成し、Artifactsとして取得できます。公開Releaseへの自動掲載は行いません。Electronの初回取得とビルドツール取得にはインターネット接続が必要ですが、完成したアプリのゲーム起動に接続は不要です。

Linux Cloudの `scripts/setup-codex-cloud.sh` はWeb開発用なので、Electron本体のダウンロードを省略します。デスクトップ版の開発・テストは、Electronを取得できるWindows環境で上記コマンドを実行してください。

配布物は `launcher-release/` に生成し、Gitには含めません。現段階ではコード署名は設定していません。WebサイトのPagesビルドにはランチャーのソース・設定・ゲームフォルダーを含めません。

ゲームウィンドウはNode.js無効・context isolation・sandbox有効です。取り込みはパス検証と容量制限を適用し、専用プロトコルで選択ゲーム内のファイルだけを配信します。ゲームにIPCやランチャーpreloadを渡しません。ランチャー画面にも外部通信を許可しません。

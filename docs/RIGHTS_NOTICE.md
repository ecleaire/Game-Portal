# 名称の使用・権利表記

`rights/index.html` に名称の説明、各権利者、非提携・非公式であること、投稿作品のライセンス対応と公式参照先を掲載しています。全12ページのフッターからアクセスできます。ログイン・規約への同意なしで閲覧できます。既存の利用規約の変更や再同意、SQL migration、Edge Function の更新は不要です。

Godot Engine・Scratch・TurboWarpの名称は制作環境・対応形式の説明や分類に使用します。公式ロゴを新たに掲載する予定はありません。名称の表示はコード・素材を再配布するライセンスへの対応とは別です。名称の使用許諾を無条件に保証する文言や、TurboWarpに独自の商標使用許諾があるという未確認の記載は掲載しません。

# 投稿済みゲームの編集

アカウント → 投稿したゲーム → 管理・編集で、サムネイル、基本情報、タグ、公開範囲、共有相手、公開日時、ゲームファイルを編集し、最後の「変更を保存」で保存します。画像・ゲームファイルは変更する場合だけ選択します。保存中は入力をロックし、ボタンの直後へ保存進捗を表示します。

`202610050020_unified_game_editor.sql`の`user.submission.save`は、既存の本人認可・タグ・公開設定の検証を使用し、ゲーム情報と公開設定を同じトランザクションで更新します。共有相手や公開日時などの検証が失敗した場合は、ゲーム情報とタグも更新前に戻します。一般ユーザーが他人のゲームを変更することはできません。

画像・ZIPの外部保管はDBと同じトランザクションにできないため、情報と公開設定の保存後に順番に行います。一部が失敗した場合は、情報は保存済みであることとファイルの保存が完了していないことを画面に表示し、選択したファイルを保持して再試行できるようにします。ゲームファイルの差し替えには従来のリビジョン検証を使用し、未完了時に既存の配信用ファイルを消しません。

サムネイルはPNG・JPEG・WebP、5MB以下です。認可済みの画像と選択したローカル画像をBlob URLとして描画するため、アカウント・投稿・管理ページのCSPの`img-src`は`'self' blob:`です。画像表示に必要な許可のみ追加し、スクリプト・Storage権限は変更していません。選択プレビューと保存後の画像をブラウザーテストの`naturalWidth`で検証します。

JSON APIはUTF-8で32KBを上限とし、最大文字数の日本語説明・操作説明・22タグ・50共有相手を同じリクエストに含められます。フィールドの文字数やタグ・共有先の上限は既存のDB/Edge検証を維持します。

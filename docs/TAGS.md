# ゲームタグ

`202610040016_game_tags.sql`を既存migrationの後に適用し、Edge Function `portal`を更新します。初期77タグはmigrationに含まれます。`supabase/tag-seed.sql`も同じ初期データを登録でき、固定IDまたは同じslugがあれば追加しません。新規構築では通常のmigration実行だけで完了します。

## DBと権限

`portal_private.tags`はid（UUID）、name、slug（全カテゴリで一意）、category、sort_order、is_active、created_atを持ちます。`portal_private.game_tags`はgame_id、tag_id、created_atを持ち、複合主キーで重複を防止します。tag_idの索引を備え、ゲーム削除時は関連だけをCASCADE削除します。タグ自体の物理削除UI/APIはありません。

両テーブルはRLS有効、公開クライアント用ポリシーなし、anon/authenticated/service_roleに直接操作権限なしです。既存のservice role専用RPCとEdge Functionを通し、毎回ユーザー・管理者のセッション、期限、失効、BAN、権限を検証します。ユーザーは自分のゲームだけを編集できます。管理者も本人専用の下書きゲームのタグは編集できません。

`tag_ids`はUUID配列です。最大8個・重複禁止・実在するタグ・有効状態をRPCで検証し、関連登録をメタデータ変更と同一トランザクションで実行します。DBトリガーもゲーム行をロックし8個の上限を検証します。有効タグの選択時にタグ行の共有ロックを取り、無効化との競合を防ぎます。編集時にすでに付いている無効タグを保持することはできますが、別ゲームに追加することはできません。タグなしも許可します。旧クライアントがtag_idsを送らない編集では既存の関連を維持します。

## 管理方法

管理者としてログインし「管理画面」→「タグ管理」から追加・編集します。名前、slug、カテゴリ（既存候補または新しいカテゴリ名）、並び順、状態を設定できます。slugは英小文字・数字・ハイフン、最大80文字、名前とカテゴリは1〜40文字です。「無効」に変更すると新規選択から外れ、既存ゲームの表示は残ります。使用ゲーム数には非公開・下書きも含めます。操作は監査ログに記録します。

slugやタグ名を変更すると既存の関連も新しい表示になります。古いslugの共有検索URLは新しいslugへ自動転送しません。初期seedは管理者の既存編集を上書きしません。初期タグには固定IDがあるため、slug変更後もseedの再実行で重複しません。

## UI・検索

投稿・本人の編集・審査のタグ編集は選択式チップです。「選択中 n / 8」を表示し、8個選択時は未選択を無効化します。選択中の再クリックで解除します。カテゴリは折りたたみ可能です。無効タグは既存関連の編集時だけ表示し、解除後に新しく選択できません。

カードは3個まで表示し残数を「+n」で表示、詳細ページは全タグを表示します。チップから`/?tag=action#games`へ移動します。複数条件は`?tag=action&tag=3d`のAND検索です。タグ絞り込みは公開カタログを取得後にブラウザーで行い、既存のゲーム名・説明検索とGodot/ScratchフィルターもANDで併用します。限定公開・下書き・予約前のゲームはカタログに含めません。旧games.jsonのゲームはtags未設定でも表示・再生できます。

一覧の絞り込みはコンパクトな開閉パネルです。選択中のチップを常に表示し、パネル内はカテゴリ切替と名前・slugの検索でタグを探せます。「クリア」で選択を一括解除します。解除・検索はページを再読み込みせず反映され、Escapeキーでパネルを閉じられます。

## API

- `POST /functions/v1/portal/tags`: 有効タグ一覧、未ログインでも利用可能。
- `admin.tags`: 無効タグと使用ゲーム数を含む一覧。
- `admin.tag.create / admin.tag.update`: name, slug, category, sort_order（文字列）, is_active（"true"/"false"）、更新時tag_id。
- `user.submission.create / user.submission.update`: 既存フィールドにtag_idsを追加。
- `admin.submission.tags`: submission_id, tag_ids。承認操作の前に保存できます。
- カタログ・公開詳細・投稿一覧の各ゲームにtags配列を追加。

# グループ共有と管理権限

## アカウント

アカウントは投稿可能ユーザー、プレイ専用ユーザー、管理アカウント、全権管理アカウントの4種類です。既存の信頼済み投稿者は投稿可能ユーザーの審査省略設定として引き続き利用できます。一般ユーザーと管理アカウントの認証・セッションは分離したままです。

管理アカウントの**所属（参加・閲覧）**と**担当（管理権限）**は独立しています。参加しても管理権限は増えません。退出しても全権管理者が設定した担当は解除されません。

| 操作 | ユーザー・プレイ専用 | 管理アカウント | 全権管理アカウント |
| --- | --- | --- | --- |
| グループへの自己参加・退出 | 不可 | 可 | 可 |
| グループ共有作品の閲覧 | 所属グループのみ | 参加グループのみ | 参加グループのみ |
| グループ名・概要の変更 | 不可 | 担当のみ | 全グループ |
| 所属ユーザーの追加・退出、アカウント作成 | 不可 | 担当のみ | 全グループ |
| 作品編集・タグ修正・審査・公開停止 | 自分の編集のみ | 担当グループの作品のみ | 全体 |
| 管理担当の付与・解除、グループ作成・無効化・公開方針 | 不可 | 不可 | 可 |
| サイト全体のユーザー管理・BAN・完全削除・タグマスタ・報告管理 | 不可 | 不可 | 可 |

担当グループがない管理アカウントは全体の管理操作を行えません。従来の管理アカウントにもこの制限が適用されます。公開済みのゲーム・通常ユーザーの既存セッションは維持されます。

## 設定方法

1. 全権管理アカウントで管理画面へログインし、「グループ管理」で作成します。
2. 「所属・設定を開く」→「担当グループ管理者」で管理アカウントIDを指定します。IDはユーザー一覧から管理アカウントの「管理」を開くと表示・コピーできます。
3. 担当者は自分の管理画面で、そのグループのユーザーを作成します。投稿可能／プレイ専用を選べ、作成と所属登録は1トランザクションです。
4. 既存ユーザーはアカウントIDで所属させられます。他の担当外グループに所属するユーザーの所属操作は全権管理者が行います。
5. ユーザーの投稿／編集画面で管理グループと「グループ内で共有」を設定します。共有先には管理グループを含めます。

グループ作成時は「下書き・グループ共有のみ」が既定です。所属ユーザーは公開・限定公開・個別共有へ変更できません。全権管理者だけが外部公開も選べる方針に変更できます。通常ユーザー自身による入退出のAPIはありません。

下書きは審査なしで本人のみ閲覧でき、担当管理者の作品一覧にも表示しません。グループ共有は通常の審査・ファイル検証・予約日時を適用します。投稿後の管理グループ変更は不可です。担当管理者は作品を下書きへ戻せます。

管理アカウントは「グループへの参加・閲覧」で参加・退出し、共有作品を開けます。一般ユーザーはアカウント画面の共有作品一覧から開きます。グループ共有作品は公開一覧、匿名の詳細・サムネイル・パッケージAPIに出ません。

## DBと権限制御

`202610090023_groups.sql` を既存migration 022の後へ適用し、Edge Function `portal`、Pagesの順に公開します。新しい秘密情報・環境変数は不要です。既存グループは自動作成しません。

- `portal_private.groups`: 名前（80文字）、概要（任意・2000文字）、利用状態、外部共有制限。
- `group_members(group_id,user_id)`: 通常ユーザーの所属。
- `group_admin_members(group_id,admin_id)`: 管理アカウントの自主参加。管理権限を持ちません。
- `group_admins(group_id,admin_id)`: 全権管理者が付与する管理担当。
- `game_submissions.management_group_id`: 管理するグループ。
- `game_group_shares(game_id,group_id)`: グループ公開先。複合主キーで重複禁止。

全テーブルはRLS有効、anon/authenticated/service_roleの直接読み書きは禁止。Edge Function経由のsecurity-definer RPCが現在のセッション、BAN／無効化、グループの有効状態、所属・管理担当、作品所有者、公開日時を確認します。公開カタログとパッケージ入口にも制約があり、クライアントの表示やrole送信では回避できません。

管理担当の解除は次のリクエストから管理を拒否します。参加グループを退出すると共有作品の取得を拒否します。一般ユーザーを所属から外す際はそのグループが管理する本人作品を下書きに戻し、関連する共有先と管理グループを外します。ファイルは本人の編集用に残り、アカウント自体は削除されません。グループ無効化は共有取得と担当管理を停止します。外部共有を制限する設定に変更すると、その管理グループの既存公開URLも即時停止します。

共有データの取得は毎回検証します。すでにブラウザーへ取得したゲームファイルを遠隔消去する仕組みではありません。Google Driveは引き続き非公開の保管先で、Webホスティングには使いません。

# 素材の権利表記・提供元

投稿フォームと投稿済みゲームの編集画面に、任意・最大8000文字の複数行欄を追加しました。素材名、作者・提供元、URL、ライセンス、必要な著作権表示などを記入できます。アカウント名や秘密情報・個人情報を書かないでください。

`portal_private.game_submissions.credits` に平文の説明テキストとして保存します。パスワード等を保存する欄ではありません。HTMLやMarkdownを実行せず、画面では textContent を使い改行を保持します。URLはテキストとして表示します。空欄の場合はゲーム詳細の権利表記カードを表示しません。

既存の投稿・編集の権限検証を通過した本人、または担当作品の編集を許可された管理者だけが変更できます。審査一覧・担当グループの作品管理にも表示します。公開・共有・下書きの閲覧権限を維持し、権利表記だけを匿名公開するAPIはありません。旧クライアントが欄を送らない場合は既存の値を保持します。文字数・型はSQLでも検証します。

`202610100026_submission_credits.sql` を適用後、Pagesを公開してください。既存のEdge Functionは任意の文字列フィールドを受け付け、認可済みSQLメタデータを返すため、Edge Functionの変更・再デプロイは不要です。

未ログインで「いいね」を押すと、ログイン案内とリンクを表示し、いいねは登録しません。ログイン後のいいね処理と非公開の本人履歴は既存のままです。

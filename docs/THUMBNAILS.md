# 投稿後のサムネイル更新

Supabaseに`202610040017_edit_submission_thumbnail.sql`を適用し、Edge Function `portal`を更新します。

投稿者は「アカウント」→「投稿したゲーム」→「管理・編集する」→「サムネイル」から画像を追加・変更できます。選択直後にプレビューを表示し、「サムネイルを追加 / 変更」で保存します。PNG・JPEG・WebP、1ファイル5MB以下に対応します。承認済み作品では公開一覧にも反映されます。ゲームZIP、タグ、公開範囲・日時、審査状態は変更しません。公開停止中は既存の編集制限に従います。

`POST /functions/v1/portal/update-thumbnail`はmultipart/form-dataのsubmission_idとthumbnailを受け取ります。本人の有効なセッションが必要です。Edge Functionはファイルサイズ、MIME、画像シグネチャを検査し、最大6MBでリクエスト読み込みを打ち切ります。SVGやHTMLは受け付けません。認証前提のメタデータRPCを保存前・保存後に実行し、所有者、BAN、セッション失効、編集可能な状態を再確認します。内部prepare/completeアクションは汎用APIのクライアント用allowlistへ追加しません。

画像は既存の非公開`portal-thumbnails`バケットに、投稿IDとランダムトークンの新しいキーで保存します。旧キーが一致する場合のみDBのthumbnail_keyを置換し、同時更新の上書きを防ぎます。失敗時は既存画像を保持します。成功後、旧オブジェクトを削除します。完了RPCの応答が途切れた場合は、すでに確定した画像を消さないため新オブジェクトを削除せず、画面更新で保存結果を確認できます。

Storage削除に失敗した旧画像や、完了結果が不明な未参照画像が残る可能性があります。いずれも非公開です。管理者が削除する場合は、game_submissions.thumbnail_keyと一致する画像を除外して、未参照であることを確認してください。クライアントにservice role keyや保管キーは返しません。

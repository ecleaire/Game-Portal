# 審査画面の編集・プレビュー

全権管理者の投稿審査一覧で「作品情報・公開設定を編集」を開くと、ゲーム名・制作環境・説明・バージョン・操作説明・権利表記・AI申告・タグ・公開範囲・共有相手・公開日時を一括保存できます。既存の `admin.submission.save` がセッション・投稿状態・所有者の有効性・グループ制約を検証し、監査ログを残します。担当グループの管理者は引き続き担当作品だけを編集でき、グループ共有または下書きへの変更に限定されます。管理グループは変更しません。下書き作品の内容編集・再生は管理者に提供しません。

「隔離してプレビュー」は、既存の `POST /download` に管理者セッションと投稿IDを送り、サーバーが `admin.submission.download` で認可したZIPだけ取得します。非公開DriveのID・秘密情報はブラウザーへ返しません。ZIPを検証し、既存の `mountPrivatePreview` で `sandbox="allow-scripts"` の不透明なオリジンのiframe内に表示します。親画面のDOM・ストレージ・セッションや外部ネットワークへアクセスさせません。管理画面・アカウント画面の厳格なCSP（インラインスクリプト禁止）は維持し、同一サイトの専用 `assets/private-preview-shell.html` に隔離してからゲームのバイナリを転送します。専用画面は親からの初期化だけを受け付け、単独で開いてもゲームや認証情報を取得しません。プレビューを閉じるとiframeを削除します。管理画面のオリジンで投稿HTMLを直接開く実装ではありません。

審査待ち・承認済み・却下済みで、下書きではない作品に表示します。承認操作・ファイルの差し替え・公開日時や共有の確認は既存フローを維持します。プレビュー自体で承認や公開は行いません。Drive所有者認証が失効している場合は既存の再認証エラーを表示します。

このUIは既存のEdge Function・SQLの認可を使用するため、追加のAPIや秘密情報の設定は不要です。プロフィール追加のmigration 030を適用し、最新Pagesを公開してください。`tests/browser/review-tools.spec.mjs` は審査前の編集、入力拒否、権利表記URL・AI申告の保存、監査記録、下書きの非公開、iframe隔離と390px/1440px表示を検証します。

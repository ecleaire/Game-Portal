# ゲームの読み込み

公開ゲーム・共有ゲームは、権限を確認するAPIから配信用ZIPを取得し、ブラウザーで展開して隔離iframeで実行します。Driveから直接プレイする構成ではありません。

ゲーム情報とZIPの取得は並列に開始します。共有ゲームへの切り替え時や失敗時は不要な通信を中止します。ZIP展開は全エントリーのパス・重複・サイズ制限を確認した後、最大4ファイルずつ並列に処理します。非圧縮ファイルは元のバッファーを参照し、不要なコピーを減らします。展開後のファイル順・GodotのHTMLと関連ファイル名・隔離実行の制約は維持します。

上限はZIP 50MB、展開後合計200MB、500エントリーです。大量のファイルを無制限に同時展開しません。権限確認を省略するキャッシュや、非公開ゲームを公開URLへ置く変更は行っていません。

実際の起動時間は通信速度、ZIPの大きさ、端末性能、Godotの初期化時間に依存します。今回の変更は通信待ちと展開処理の効率を改善するもので、特定の秒数や倍率を保証するものではありません。Godotでは不要な素材の除外やリリース用Web書き出しで配信サイズを減らすと、初回読み込みにも効果があります。

検証: mixed stored/deflate ZIPの内容一致、重複・パストラバーサル・サイズ不一致の拒否、ブラウザーでの公開/共有ゲーム再生と隔離プレビュー。
